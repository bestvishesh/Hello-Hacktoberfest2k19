# Hello-HacktoberFest2K19
It is a repo in which anyone can contribute for a Hacktober Fest 2k19 t-shirt.
### What is Hacktoberfest?
Hacktoberfest is a month-long celebration of open source software run by DigitalOcean and DEV.Hacktoberfest is open to everyone in our global community.To participate, four pull requests must be submitted to public GitHub repositories.You can sign up anytime between October 1 and October 31.

## Step 1:
### Register Yourself for Hacktober Fest 2k19 [Click Here](https://hacktoberfest.digitalocean.com)
## Step 2:
    Fork this repository to your own profile.
## Step 3:
    Create Hello World file in any programming language or markup language. 
## Step 4:
    Make a pull request thats it. (You have to create at least four pull request)


## File Descriptions

*   **First.java**: A Java program that declares an integer variable `num`, assigns it the value 100, and then prints "this is num100" to the console.
*   **LICENSE**: Contains the MIT License text, outlining the permissions and conditions for using the software in this repository.
*   **README.md**: The main README file for the repository. It describes Hacktoberfest and provides instructions on how to contribute.
*   **euler method.cpp**: A C++ program that implements Euler's method for solving ordinary differential equations. It takes initial values (x0, y0), step size (h), and the point of evaluation (xn) as input, and then it iteratively calculates and prints values of x and y.
*   **file.java**: A simple Java program that prints "Hello World!" to the console.
*   **file.py**: A Python script that prints "Hello, world!" to the console.
*   **first.php**: A PHP script that echoes "Hello World!" to the output.
*   **first.py**: A Python script that prints "hello octoberfest'19 " to the console.
*   **friend_class.cpp**: A C++ program demonstrating the concept of a friend class. It defines two classes, `twovalues` and `Min`. The `Min` class is a friend of `twovalues` and has a method `min` that finds the minimum of the two integer members of a `twovalues` object. The `main` function creates objects of these classes and prints the minimum value.
*   **hello-world.php**: Another PHP script that echoes "Hello World!" to the output.
*   **hello.go**: A Go program that prints "hello world" to the console.
*   **hello.hs**: A Haskell program that prints "Hello World!" to the console.
*   **hello.sh**: A shell script that echoes "Hello World" to the console.
